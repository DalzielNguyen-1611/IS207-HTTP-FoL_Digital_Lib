## 🎯 4. MỤC TIÊU CỦA ĐỒ ÁN

Repository này được xây dựng nhằm phục vụ cho đồ án môn học với các mục tiêu chính:
- **Tổ chức kiến trúc 3-Tier chuẩn mực**: Tách bạch hoàn toàn giữa Giao diện (Presentation Tier), Xử lý nghiệp vụ & RESTful API (Application Tier với 100% PHP thuần OOP), và Lưu trữ dữ liệu (Data Tier với MySQL chuẩn hóa 3NF).
- **Số hóa nghiệp vụ IT Support & cứu hộ thiết bị thực tế**:
  - **Khách hàng**: Đặt lịch cứu hộ thiết bị (PC, Laptop, Mạng), chọn khung giờ và theo dõi tiến độ ca trực realtime.
  - **Điều phối viên (Dispatch)**: Giám sát toàn bộ phiếu yêu cầu chờ xử lý, trạng thái trực ca của kỹ thuật viên và phân công tức thời.
  - **Kỹ thuật viên (Technician)**: Tiếp nhận ca làm việc, nghiệm thu hoàn tất dịch vụ, xuất hóa đơn linh kiện và quản lý ví thu nhập.
- **Xây dựng Backend RESTful API độc lập**: 100% PHP thuần OOP, PDO Prepared Statements phòng chống SQL Injection, chuẩn hóa JSON response và CORS.
- **Tối ưu trải nghiệm người dùng**: Thiết kế giao diện Dashboard và Portal hiện đại, responsive, trực quan, hỗ trợ mô phỏng hoạt động kể cả khi chưa kết nối Database.

## 🚀 6. HƯỚNG DẪN CÀI ĐẶT & KHỞI CHẠY

### Cách 1: Sử dụng XAMPP (Khuyên dùng)
1. Bật **Apache** và **MySQL** trong bảng điều khiển **XAMPP Control Panel**.
2. Sao chép thư mục dự án vào thư mục web root của XAMPP:
   ```text
   C:\xampp\htdocs\mini_project\
   ```
3. Mở trình duyệt và truy cập các cổng:
   * **Cổng điều hướng Frontend:** [http://localhost/mini_project/mini-project-techCare-platform/frontend/index.html](http://localhost/mini_project/mini-project-techCare-platform/frontend/index.html)
   * **Cổng kiểm tra Backend PHP:** [http://localhost/mini_project/mini-project-techCare-platform/backend/index.php](http://localhost/mini_project/mini-project-techCare-platform/backend/index.php)
   * **API Lấy danh sách phiếu:** [http://localhost/mini_project/mini-project-techCare-platform/backend/api/bookings.php](http://localhost/mini_project/mini-project-techCare-platform/backend/api/bookings.php)
4. *(Tùy chọn)* Nạp CSDL: Mở [phpMyAdmin](http://localhost/phpmyadmin), tạo CSDL tên `techcare_db` và Import file [mini-project-techCare-platform/database/schema.sql](mini-project-techCare-platform/database/schema.sql). *(Lưu ý: Nếu chưa bật MySQL, hệ thống vẫn có cơ chế Mock Data tự động để demo mượt mà không bị gián đoạn).*

### Cách 2: Sử dụng PHP Built-in Server
Nếu máy tính đã cài đặt môi trường PHP:
1. Mở Terminal / PowerShell tại thư mục gốc của dự án:
   ```bash
   php -S localhost:8000
   ```
2. Truy cập qua trình duyệt:
   * **Frontend:** [http://localhost:8000/mini-project-techCare-platform/frontend/index.html](http://localhost:8000/mini-project-techCare-platform/frontend/index.html)
   * **Backend:** [http://localhost:8000/mini-project-techCare-platform/backend/index.php](http://localhost:8000/mini-project-techCare-platform/backend/index.php)

*(Hoặc mở trực tiếp từ bên trong `mini-project-techCare-platform`: `cd mini-project-techCare-platform && php -S localhost:8000`, sau đó truy cập [http://localhost:8000/frontend/index.html](http://localhost:8000/frontend/index.html)).*

### Cách 3: Trình chiếu giao diện tĩnh (Static Presentation)
Có thể mở trực tiếp file `mini-project-techCare-platform/frontend/index.html` trên bất kỳ trình duyệt nào để trải nghiệm và thuyết trình giao diện mà không cần thiết lập Web Server.

## 📡 7. DANH MỤC RESTFUL API PHP (APPLICATION TIER)

| Endpoint PHP | Phương thức | Mô tả chức năng |
| :--- | :---: | :--- |
| `api/auth.php?action=login` | `POST` | Đăng nhập tài khoản (Khách hàng, KTV, Điều phối) |
| `api/auth.php?action=register` | `POST` | Đăng ký tài khoản người dùng mới |
| `api/auth.php?action=profile` | `GET` | Lấy thông tin tài khoản đang đăng nhập |
| `api/bookings.php` | `GET` | Lấy danh sách toàn bộ phiếu yêu cầu / tickets |
| `api/bookings.php?id={id}` | `GET` | Xem chi tiết ca trực (ví dụ: `BK-3895` hoặc `TC-HOME-3895`) |
| `api/bookings.php` | `POST` | Tạo phiếu đặt lịch sửa chữa / cứu hộ IT mới |
| `api/bookings.php?id={id}&action=status` | `POST` / `PUT` | Cập nhật tiến độ ca sửa chữa (`assigned`, `in_progress`, `completed`) |
| `api/dispatch.php?action=dashboard` | `GET` | Thống kê số liệu, hàng đợi pending, KTV trực ca cho điều phối |
| `api/dispatch.php?action=assign` | `POST` | Phân công KTV cho ca cứu hộ |
| `api/dispatch.php?action=technicians-live` | `GET` | Danh sách trạng thái realtime của tất cả kỹ thuật viên |
| `api/technicians.php?action=schedule` | `GET` | Xem lịch trực ca & phân công nhiệm vụ của KTV (`#NV-204`) |
| `api/technicians.php?action=complete&booking_id={id}` | `POST` | Nghiệm thu hoàn tất ca & xuất hóa đơn linh kiện |
| `api/technicians.php?action=wallet` | `GET` | Xem số dư ví thu nhập & lịch sử nhận tiền |
| `api/technicians.php?action=withdraw` | `POST` | Tạo yêu cầu rút tiền về tài khoản ngân hàng |
| `api/reviews.php` | `POST` | Khách hàng gửi đánh giá sao & nhận xét sau sửa chữa |
